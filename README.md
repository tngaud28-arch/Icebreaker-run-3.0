# Icebreaker Run — Full Modular Version
## Run
Use a static server:
`npx serve .`
## Controls
Arrow keys/A/D, swipe left/right, or touch buttons.
## Cloudflare Pages
Upload to GitHub → Workers & Pages → Create Pages → Framework None → Build command empty → Output directory `/`.
## Modules
Game state, Boat, Iceberg, collision, spawner, input, audio, storage, score manager, renderer, ocean renderer, and UI manager are separated into individual files.
